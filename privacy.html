Política de privacidad

Casa accede únicamente a la cuenta de Google de su propietario, con permiso para leer y marcar correos y para gestionar su calendario.

  • Los datos se procesan solo para mostrar citas, pendientes y avisos al propio hogar.
  • No se venden, comparten ni transfieren a terceros.
  • No se usan para publicidad ni para entrenar modelos.
  • El acceso se puede revocar en cualquier momento desde https://myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.
